# Blog list

Welcome to the **blog list** app, built with Next.js as part of the Full Stack Open course.

## What you can do

- Read the blogs other people have shared and search them by title
- Register and log in to add your own blogs
- Like blogs you enjoy
- Keep a personal reading list and mark blogs as read
- Generate an API token on your own page and use it to fetch your data as JSON

## How it is built

The app uses the Next.js App Router with Server Components and Server Actions. Data is stored in a PostgreSQL database that is accessed with [Drizzle ORM](https://orm.drizzle.team/), and authentication is handled with [Auth.js](https://authjs.dev/).
